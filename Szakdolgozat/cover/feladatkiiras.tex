\large\textsc{\textbf{Szakdolgozat Feladat}}
\end{center}
\vspace{0.5cm}

Varga István Hunor (NHJYQC) programtervező informatikus jelölt részére.

\bigskip
\noindent\textbf{A szakdolgozat tárgyköre:} Adatbáziskezelés, Grafikus felhasználói felület

\bigskip
\noindent\textbf{A szakdolgozat címe:} Relációs séma és diagram szerkesztő alkalmazás fejlesztése

\bigskip
\noindent\textbf{A feladat részletezése:}

\medskip

\emph{A szakdolgozat egy diagram szerkesztő alkalmazás fejlesztését mutatja be, melynek a segítségével relációs sémák definiálhatók, és diagramok hozhatók létre. A séma megadása történhet a grafikus felületen vagy pedig szabványos SQL lekérdezésekből importálva. Az alkalmazás támogatja az automatikus elrendezést, melyhez kapcsolódóan a szakdolgozat vizsgálja a diagramon az élek megfelelő elhelyezésének a problémáját. A relációs séma diagramját többféle formátumban exportálhatóvá teszi (például PNG és SVG formátumokban). A program lehetőséget ad a diagram megjelenésének beállítására a felhasználó által megadott paraméterekkel, előre összeállított témákkal. Az alkalmazás Java programozási nyelven készül. A grafikus megjelenítés Java/Swing segítségével kerül megvalósításra.}

\medskip
